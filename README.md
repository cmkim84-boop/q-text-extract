# Q 텍스트 추출

이미지(보도자료 캡처, 스크린샷, 사진)에서 글자를 읽어 복사할 수 있는 글로 바꿔 주는 윈도우 업무 프로그램. Q 시리즈(Q 이미지 편집기, Q 수치 계산기)와 같은 다크 에디터 톤이고 포인트 컬러만 민트(#1fc98e)다.

## 동작 방식
- 글자 인식은 **윈도우에 내장된 OCR(Windows.Media.Ocr)** 을 쓴다. 인터넷 연결이 필요 없고 설치 파일이 커지지 않는다.
- 이 PC에 한국어 OCR 기능이 설치되어 있어야 한다. (설정 → 시간 및 언어 → 언어 및 지역 → 한국어 → 언어 옵션 → 광학 문자 인식)
- 이미지 열기 / 끌어다 놓기 / Ctrl+V 붙여넣기 → 자동 인식 → 결과 글을 바로 고치고 복사(Ctrl+Shift+C) 또는 txt 저장(Ctrl+S).
- 이미지 위를 드래그하면 그 영역만 다시 읽는다. (우클릭/Esc 로 전체 영역)
- 정리 옵션: 줄바꿈 정리(문단 안 줄바꿈 제거), 공백 정리, 숫자 강조(숫자+단위를 색으로 표시해 원본과 대조).

## 파일
| 파일 | 역할 |
|---|---|
| app.py | 화면과 동작 |
| ocr_engine.py | 글자 인식 (윈도우 OCR, 개발용 대체 엔진, 빌드 후 자동 점검 `--selftest`) |
| textops.py | 줄 → 문단 정리, 공백 정리, 숫자 위치 찾기 (tests/ 에서 시험) |
| style.py | 색과 스타일시트 |
| feedback.py | 종료 때 의견 팝업 (Q 이미지 편집기와 같은 방식) |
| feedback_apps_script.gs | 의견 받는 구글 시트 코드 ('프로그램' 열 추가본) |
| installer.iss, build.bat, .github/workflows | 설치 파일 만들기 |

## 설치 파일 만들기
GitHub 에 올리고 Actions 의 `Build Windows installer` 를 실행하면 `QTextExtract-Setup.exe` 가 만들어진다. 이 과정에서 묶인 프로그램의 OCR 부품이 실제로 도는지 점검하고(로그에 `RESULT: PASS`), 실패하면 설치 파일을 만들지 않는다.
내 PC 에서는 `build.bat` 을 실행한다.

## 개발용 실행
`python app.py` — 윈도우가 아닌 환경에서는 pytesseract 로 대신 읽는다(화면 확인용, 정확도 기준 아님).
